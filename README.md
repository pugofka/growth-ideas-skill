# growth-ideas

A Claude Code skill that generates evidence-grounded growth hypotheses for a B2B product. You get a few ideas the owner can test within two weeks, not a long backlog.

Every hypothesis is grounded in a product context file. It cites the facts it relies on, respects what the owner has already rejected or approved, and comes with the cheapest test and a kill criterion.

## Why

Asked for "growth ideas", a model without context confidently suggests things that do not fit the business:
- tests on a customer base that does not exist;
- pivots;
- a "free audit" that needs the client's data;
- features the product already has;
- a head-on "switch from the market leader" campaign with no feature parity behind it.

This skill makes the model ask for context first. It then reasons from facts and filters out ideas that break the owner's constraints.

## What it does

1. **Context first.** Reads `growth-context.md`, a file of numbered facts, red lines, and lists of what was already tried or approved. If the file is missing or key sections are empty, the skill asks for them instead of guessing.
2. **Scope.** Offers the directions that follow from the facts: channels, website and product, marketplaces, B2B partners, retention. Then asks which ones to cover.
3. **Customer job (JTBD).** Works out what triggers the search, how customers solve the problem today, and what scares them.
4. **Opportunity tree, then an asset pass.** A second, independent pass goes through existing assets: content, customers, adjacent products, directories. It catches obvious moves the first pass misses.
5. **Filtering.** Drops repeats of rejected or approved ideas, red-line violations, ideas that rely on missing resources or invented numbers, and absurd leader-switch campaigns. Hygiene fixes go to a separate "Step 0".
6. **Hypotheses.** Each one includes: insight with fact IDs, mechanism, first step this week, metric and threshold, cheapest test, how it fails, and kill criterion.
7. **Output in two blocks by default.** A: channels and company. B: website and product improvements that affect sales. Each block has 3–5 hypotheses. After them come Step 0 (hygiene) and a list of assumptions to check.

The skill replies in the user's language. It always reads a reference on the Russian market:
- Yandex and Google;
- local channels;
- ad marking (erid);
- consent for promotional messages;
- personal data law (152-FZ);
- seasonality.

## Install

As a Claude Code plugin:

```
claude plugin marketplace add pugofka/growth-ideas-skill
claude plugin install growth-ideas@pugofka
```

Or with the [skills](https://github.com/vercel-labs/skills) CLI:

```
npx skills add pugofka/growth-ideas-skill
```

## Usage

1. Copy [`skills/growth-ideas/templates/growth-context.md`](skills/growth-ideas/templates/growth-context.md) to your project root and fill it in. Give every fact an ID (F1, F2…). The sections "Red lines" and "Already tried / rejected" matter most.
2. Ask Claude something like:

   > Using `growth-context.md`, give me growth hypotheses for the next two months.

   You can also invoke the skill directly: `/growth-ideas:growth-ideas` when installed as a plugin, or `/growth-ideas` when installed with the skills CLI.

## Evals

`evals/` contains 10 cases on fictional products. Each case checks one behaviour:

| Case | Checks |
|---|---|
| `asks-for-context-when-missing` | Asks for context instead of guessing |
| `respects-rejected-and-approved` | Does not repeat rejected or approved ideas |
| `no-invented-numbers` | No invented traffic, conversion, or market numbers |
| `cites-facts-and-kill-criteria` | Fact IDs, cheapest test, kill criterion |
| `hygiene-is-step-zero` | Fixes are separated from growth hypotheses |
| `no-absurd-leader-switch` | No "switch from the leader" without parity |
| `company-voice` | Client-facing copy speaks as "we" |
| `proactive-site-block` | Separate block of website and product improvements |
| `russian-market-compliance` | Personal data consent, ad marking, messaging consent |
| `replies-in-user-language` | Russian request → Russian output |

Run them with and without the skill:

```
claude plugin eval . --runs 1 -j 4 --ablation with-without --scaffold \
  --judge-model claude-sonnet-5-5 --trust-plugin --no-publish --allow-tools Write Edit
```

Last run, 2026-10-15, on Claude Opus 5.5, one run per case:
- with the skill, all 10 cases pass;
- without it, 5 cases score below 1: four score 0.00 (asking for context, leader switch, site block, compliance), and the criteria case scores 0.25;
- mean Δ +0.47, cost $4.54.

The cases are generated by `tools/gen-evals.py`. Edit the generator, not the case files.
